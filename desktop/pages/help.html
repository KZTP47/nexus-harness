What is this?

Nexus Harness is a helper that works on your code with you. You say what you want in plain words. It reads the project, makes a plan, edits the files, runs your checks, and has a second model review the result.

The four tabs

  • Start here tells you what is still missing, and lets you ask for a change.
  • Checks holds your tests. Each one says what to do and what a good result looks like.
  • Workflow is for later. It shows the agents as boxes you can rewire.
  • Memory and Prompt history show what the harness has learnt and how its instructions changed.

Where your work lives

Everything runs on this machine. The harness keeps its own files in a folder named .harness inside your project. Nothing is uploaded unless you point it at a hosted model yourself.

If a run goes wrong

A failed run puts every file back the way it was. You can also make a snapshot at any time with harness checkpoint create.
