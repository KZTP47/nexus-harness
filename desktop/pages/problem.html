Something went wrong

Most of the time this means one of these:

  • Python 3.11 or newer is not installed, or the app cannot find it. Install it, then start the app again.
  • The folder you chose is not the harness. Pick the folder that has src and scripts in it. The app takes the harness's own code from beside itself, so a plain download works with nothing installed - but it has to be pointed at the right place.
  • Something is missing from the download. If src/our_harness is not there, the copy is incomplete. Download it again.

If Python lives somewhere unusual, set the HARNESS_PYTHON environment variable to its full path before starting this app. If you would rather install the harness into Python, open a terminal in the project folder and run python -m pip install . - it is not needed, and it works too.
