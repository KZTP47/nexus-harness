The installed app carries its own supported Python and Nexus code. Most startup failures now mean one of these:

  • The installed package is incomplete. Reinstall the same checksummed release; no separate Python installation is needed.
  • The selected project moved or cannot be read. Choose the code folder you actually want Nexus to work on.
  • The project's machine-local settings need review. Nexus will show the exact file and consequences before offering trust.

Source developers may still set HARNESS_PYTHON; that external fallback must be Python 3.11 or newer.
