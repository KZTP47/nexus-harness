# Nexus Harness 0.2.13

This stable release includes the saved-answer, project-context and screenshot
input fixes documented in [0.2.12](0.2.12.md), plus a shorter, bounded release
workflow. The 0.2.12 candidate was cancelled before publication.

- CI and release runs target ten minutes with a fifteen-minute total budget,
  enforced by a cancellation guard and a pre-publication budget check.
- Both supported Python versions run their complete test suites in eight
  independent shards. The browser panel shares one setup; duplicate packaging
  tests are removed.
- Release builds one installer. Installed-app, long-horizon, team-chat and
  shortcut checks run in parallel. Public byte verification and installation
  from the source ZIP also run in parallel.
- The installer, signer identity, checksum, approval, isolation and recovery
  checks remain required. A timeout or missing check is a failed run.

The implementation and ownership map is in [CI budget](../CI_BUDGET.md).
