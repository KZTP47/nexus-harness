# Nexus Harness 0.2.26

Full project access now covers Nexus's missing-reviewer fallback. A team with
valid full access continues with deterministic checks when no independent
reviewer is available, without another permission question. Saved redundant
review questions recover against their exact proposal and access binding.
An available reviewer, read-only access, rejected proposals, collision checks
and final verification retain their existing owners.

Nexus gains 24 tool entries: live glob and regex search, five Git inspection
tools, tool discovery and settings inspection, public web search, local skill
reading, notebook reading/edit proposals, exact text edit proposals, code
navigation and LSP queries, MCP resources/templates/status and tool calls, a short cancellable
wait, and full-access command execution/file writing in private agent copies.
The agents keep their own native tools. Nexus collects private edits for its
normal review, verification and publication flow.

The [adoption inventory](../CLAW_TOOL_ADOPTION.md) accounts for all 55 built-ins
in the inspected Claw Code registry, including existing Nexus task/worker/team
and scheduling equivalents. It documents optional Git/LSP/MCP dependencies,
bounded outputs, command timeouts, stateless code execution, and the deliberate
exclusion of Claw's test-only permission hook from production.

Effectful Nexus commands are reserved before execution. After an interruption,
a saved result is reused; a reservation without a result is reported as an
unknown outcome and is not silently executed again. Git reads the selected
repository explicitly; private file tools read unpublished agent work.

The release acceptance runs toolbox and full-access recovery tests with the
packaged Python runtime and packaged product sources, in addition to the
existing installed-app, collaboration, recovery and shortcut checks.

This Windows build is unsigned. The release workflow publishes the measured
installer size, SHA-256 and offline bundle. Allow at least 2 GiB during installation.
