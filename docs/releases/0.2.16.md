# Nexus Harness 0.2.16

This release retains the agent and CI improvements described in
[0.2.15](0.2.15.md). That candidate passed all 21 source CI jobs in 10 minutes
12 seconds, but its installed long-horizon test encountered a startup race
before any agent work began. Its unpublished tag remains as history.

Installed collaboration tests now wait for the panel's JavaScript runtime
before configuring a board. Reaching an HTTP URL alone does not prove that the
document scripts have initialized. Missing initialization still fails within
the existing timeout; the tests do not retry agent actions or skip assertions.

Normal CI now runs the full suite once on Python 3.13. The duplicate eight-part
Python 3.11 suite is removed and replaced by a short compatibility check.
Installed checks and public download verification remain required. The ten-minute
target, fourteen-minute cancellation point, and fifteen-minute workflow budget
are unchanged.
