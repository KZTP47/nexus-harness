# Nexus Harness 0.2.20

This release combines the BLOX-REMOVER branch with the latest goal-completion,
Windows verification, delivery, and chat improvements.

- Agents retain their conversation and recovery context through provider
  interruptions, with clearer progress and reconnection controls.
- Windows browser verification handles long launch commands, reuses the shared
  AppContainer identity across peer processes, and reports native failures
  without losing the underlying diagnostic to serialization errors.
- Completion requires delivery evidence from the user's selected project.
  Working-copy reports are labelled separately from confirmed delivered files.
- OPEN buttons beside delivery destinations and receipt paths open the folder
  or reveal the file in Explorer.
- Right-click chats to archive, delete/purge, rename, pin/unpin, or cancel.
  Custom names preserve engine identity; purge keeps delivered project files.
- Team controls collapse, remember their state, and call attention to required
  user input. A Permissions control beside the chat buttons offers Read only,
  Ask before commands, and Full project access for that chat.

The Windows installer is explicitly unsigned. Its SHA-256 file verifies the
download bytes, and the offline ZIP includes the versioned installer.
