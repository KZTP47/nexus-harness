# Nexus Harness 0.2.12

Agents retain explicit answers across long conversations and distinguish the
selected project from temporary provider directories. The shared-chat decision
form sends your actual answer separately from the agent's question wording.

- Keep team answers available to both participants, retain private answers for
  their original recipient through reviews and task handoffs, and reject stale
  or changed submissions. Retrying the same saved submission cannot apply it twice.
- Suppress an already answered clarification when only its presentation changes
  and no new evidence justifies asking. Eligible older stuck conversations offer
  **Reconsider using saved answers**, which asks the team to inspect its existing
  context without inventing an answer or approving an action.
- Send original screenshot bytes directly to Claude and Codex. Detect supported
  image types from the bytes, retain dimensions and content hashes, and report
  missing or changed attachments instead of silently continuing without them.
- Pass explicit project and working-copy identity to provider turns. Exact typed
  paths and URLs take precedence over uncertain screenshot transcription.
- Ignore stale goal responses that would restore old question cards or replace
  another chat's state. Require terminal provider results before accepting a
  successful response. Keep the open chat refreshing until its final saved
  completion message arrives, including when that message is delayed.

These changes adapt selected solutions from t3code; see
[the source map and evaluation](../T3CODE_ADOPTION.md). They preserve Nexus's
existing command approval, verification and concurrent workspace boundaries.
They do not guarantee perfect screenshot reading or establish a model-quality
benchmark. Unsupported provider image input is reported explicitly.
