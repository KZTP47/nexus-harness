# Nexus Harness 0.2.15

This release retains the agent input, workspace isolation, and CI improvements
described in [0.2.14](0.2.14.md). That candidate passed source CI in 10 minutes
32 seconds and all four installed acceptance modes, but was not published.
Its tag remains as history.

Release packaging now creates the offline ZIP alongside the longest installed
check, removing that work from the path that delays every installed check.
The same installer, checksum, identity validation, and public download checks
remain required.

A single transient GitHub job-status read timeout receives one bounded retry. That retry
uses the existing workflow clock; persistent failures still stop the run.
Authentication failures, malformed responses, and failed checks are not ignored.

The target remains ten minutes, with cancellation at fourteen minutes and a
fifteen-minute whole-workflow budget. See [CI budget](../CI_BUDGET.md).
