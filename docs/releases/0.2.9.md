# Nexus Harness 0.2.9

This release fixes unnecessary pauses during shared agent work and makes the
agents' public progress and tool activity visible in chat.

- Fix polite team requests such as “can you guys add a shop” being incorrectly
  classified as read-only. Resume refreshes obsolete verification observations
  while retaining applied files and selected test commands.
- Offer proposed-change inspection only to targeted reviewers. Reviewers can
  read the proposal before giving a verdict, and correctable tool requests are
  returned to the agent without terminating the conversation.
- Let distinct discussion continue without requiring artificial file changes.
  New shared goals have no hidden cumulative call ceiling; explicit user limits
  remain exact, and saved legacy limits are preserved.
- Allow read-only tool exploration across durable provider responses while
  preserving per-response consumption, receipts, and replay protection through
  restart. New connected-agent chats continue while progress continues.
- Show public progress, tool inputs/results/errors, and durable activity in the
  chat. Private internal model reasoning is not available.
- Include the unreleased repairs for response-scoped tool identities, complete
  file-read pagination, action-format recovery, durable conversation history,
  and clearer saved-goal diagnostics.

Configured tests still require real passing evidence. When no project checks
exist, Nexus says that no tests ran and requires current artifact evidence and
team agreement. User pause/cancellation, file boundaries, provider identity,
uncertain-delivery reconciliation, and explicit budgets remain enforced.
