# Nexus Harness 0.2.28

Facilitator conversations coordinate project changes at the operation level,
allowing discussion and inspection without reserving the project for an entire
conversation. Overlapping writes retain project coordination and recovery.

Team conversations include improved follow-up attachment context, peer delivery,
provider activity visibility, and recovery around provider waits and response
transport. Browser relay handling improves page identity and response delivery.

Background assistance adds optional watched-input scheduling and local hybrid
memory retrieval. Goal status distinguishes recorded responses from verified
project results. See the background assistance and facilitator documentation for
configuration and limitations.

Tests were explicitly skipped for this release at the user's request. This is a
locally packaged release; it does not claim a passing CI or installed-app test
run. Packaging performs its built-in runtime and source-containment checks.

The Windows installer is unsigned and includes a SHA-256 checksum and an offline
installation bundle.
