# Nexus Harness 0.2.11

Saved chats can now work concurrently on the same selected project. Each chat
has an independent working copy; this supports non-Git projects and preserves
uncommitted files.

- Run provider work concurrently while keeping chat history, tools, control
  actions, task budgets and file transactions scoped to the exact goal.
- Synchronize unrelated project changes before final checks, reopen team review
  when necessary, then apply only the verified delta with rollback backups.
- Pause conflicting edits with the exact paths and retained working-copy
  location. Never overwrite another chat's result or announce completion before
  the verified changes reach the selected project.
- Review and approve newly discovered test commands for the exact chat copy.
  Another chat cannot inherit that approval.
- Recover working copies and interrupted publication using authenticated state
  and the original transaction identity. Settled pre-upgrade chats can adopt
  isolation while preserving files, questions and spent budgets.

Provider capacity still applies. Final verification/application is serialized;
other chats can continue their work. Legacy workflows that mutate the original
project retain exclusive ownership until their effects settle. Working copies
are retained for inspection and recovery and require additional disk space.
