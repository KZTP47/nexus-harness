# Nexus Harness 0.2.18

Chats waiting for an agent question or user decision now pulse amber in the
conversation sidebar, including while another chat is open. A "Needs your
input" label explains the cue without relying on color alone.

- Pending goal questions and approvals, saved work paused for user input, and
  structured questions arriving in background chat replies trigger the cue.
- Ordinary replies, progress messages, and question marks in prose do not.
- Opening a chat keeps its cue visible until the input request is resolved.
  Answering, completing or cancelling the corresponding goal clears its cue.
- Saved goal and work-recovery state restores the cue after restart. Changed
  project identities and archived chats cannot inherit another chat's cue.
- Reduced-motion preferences replace the pulse with a steady amber highlight.

Verified locally with 83 focused chat, navigation, decision and browser tests,
including actual animated sidebar rendering. Published from an isolated source
snapshot; unrelated local work is excluded. GitHub CI was not a release gate.

The Windows installer is unsigned. Its accompanying SHA-256 file verifies the
download bytes; Windows may show an unknown-publisher prompt.
