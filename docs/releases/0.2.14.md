# Nexus Harness 0.2.14

This release includes the agent input fixes and CI parallelism described in
[0.2.13](0.2.13.md). The 0.2.12 and 0.2.13 candidates were cancelled before
publication; their tags remain as history.

The complete Checks workflow passed in 8 minutes 54 seconds. All four installed
acceptance modes also passed for the 0.2.13 candidate, but an excessive
publication reserve rejected it at 10 minutes 20 seconds. The final public
source-ZIP check now has a two-minute limit, compared with its measured
66-second run. Publication reserves three minutes for its own one-minute write
and the parallel two-minute public verification jobs.

The whole-workflow fifteen-minute ceiling and cancellation at fourteen minutes
remain enforced. Required tests, installed-app checks and public verification
are unchanged. See [CI budget](../CI_BUDGET.md).
