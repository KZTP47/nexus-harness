            What you can do here
            
                                        
              
                                      • Chain up the jobs you already run. Your checks, your tests,
                a scan of the code for credentials, a look at the repository.
                                        • 
              
                                      • Stop the work when something is wrong. A gate lets it go on
                only if what came before passed - all of it, or any of it.
                                        • 
              
                                      • Try again, and wait before you do. Up to five tries, with the
                same short wait each time or a longer one each time.
                                        • 
              
                                      • Do something when it breaks. A step can be set to run only when
                something before it failed, or to run whatever happened.
                                        • 
              
                                      • Stop and ask a person. The run waits, shows your question, and
                carries on when somebody says so.
                                        • 
              
                                      • Ask an assistant one question part way through, and keep the
                answer with the run.
                                        • 
              
                                      • Run one of your other pipelines as a single step, instead of
                copying its steps.
                                        • 
              
                                      • Ask you a couple of questions when it starts, so one saved
                pipeline covers the quick run and the full one.
                                        • 
              
                                      • Run less than all of it: one step on its own, or from the step
                that broke onwards.
                                        • 
              
                                      • Keep what you had. Every save keeps the version before it, and
                any of them can be put back.
                                        • 
              
                                      • Show you what happened: every box lights up as the work reaches
                it, and a timeline says which step was the slow one.
                                        • 
              
                                      • Start from a ready-made one. Ten of them, with a search box.
