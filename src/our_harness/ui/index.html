Welcome

Four short steps get this project ready. You can do them in any order.

Looking at your project.

    Ask for a change

    Say what you want in your own words. The harness plans it, edits the files, runs your checks, and reviews the result.

    A run stops on its own if it fails twice or runs out of time. Files are restored when a run fails.

    What the other tabs are for

    You do not need any of them to get started.

    Checks
    Your tests. Each one says what to do and what a good result looks like. Run them any time.
    Workflow
    For later. It draws the agents as boxes so you can change who does what, and in which order.
    Memory
    What the harness has read and remembered about this project, and which agent wrote each note.
    Prompt history
    The instructions the harness gives its agents, and how they changed. Nothing changes without your review.

    Keyboard controls

    Tab enters the graph. Arrow keys choose a node. C starts a connection. Enter selects. Control plus an arrow moves a node. Delete removes it. Control+Z restores the last graph edit.

    100% Arrow: focus. Ctrl+Arrow: move. C: connect.

    Use arrow keys to focus nodes. Press C to start a connection and Enter to select a target.
